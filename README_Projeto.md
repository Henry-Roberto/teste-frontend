## 📌 Angular Hero
This project was developed as a technical test and aims to create a developer CRUD.

## 🚀 Technologies  
- **Angular 16**  
- **Node.js v18.20.7**
- **NPM v10.8.2**


## 📦 Installation

1. **Clone the repository:**  
   ```bash
   git clone https://github.com/Henry-Roberto/angular-hero.git
   cd angular-hero
   ```  

2. **Install dependencies:**  
   ```bash
    cd apps/backend && npm install && cd ../..
    cd apps/frontend && npm install && cd ../..
   ```  

3. **Start the backend project:**  
  
   ```bash
   npm run start:backend
   ``` 

3. **Start the front project:**  
  In another terminal you must start the front end part

   ```bash
   npm run start:front
   ``` 
   
4. **Access the project:**
  Access in browser: `http://localhost:4200/`  

## 🧪 Running Tests

To run unit tests, use the following command:
```bash
 npm run test:frontend
```
